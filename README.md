## Penjelasan Program
Pada tugas kecil 1 Strategi Algoritma ini kita diminta untuk membuat program yang dapat menemukan satu solusi pada Queens, gim logika yang tersedia pada situs jejaring profesional LinkedIn, dengan menggunakan algoritma brute force. Tujuan dari game ini adalah menempatkan queen pada sebuah papan persegi berwarna sehingga terdapat hanya satu queen pada tiap baris, kolom, dan daerah warna. Selain itu, satu queen tidak dapat ditempatkan bersebelahan dengan queen lainnya, termasuk secara diagonal.

Program ini dapat dijalankan pada lingkungan Windows maupun Linux.

1. Python 3.x
2. Library Eksternal (perlu diinstal):
  ```bash
  pip install matplotlib colorama
  ```
  Standard Library Python (sudah tersedia): os, time, random.
  
  Instalasi library:

2. Masuk ke folder sumber kode:

3. Jalankan program dengan perintah:
